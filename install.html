SlimeCheat

A hack panel inside SlimeBeep for Bondage Club. Made by SlimeQueenSamantha.

⚠ First: SlimeBeep

SlimeCheat opens inside SlimeBeep's window, so you need SlimeBeep (or turn it on in FUSAM). No SlimeBeep yet? The SlimeBeep + SlimeCheat bookmark below loads both.

🔖 Bookmark (no extension needed, phones too)

  1. Show your bookmarks bar (Ctrl + Shift + B).
  2. Drag one of these onto it:
    💻 SlimeCheat 🫧💻 SlimeBeep + SlimeCheat
    SlimeCheat alone if SlimeBeep already loads by itself (FUSAM or its userscript); both if not.
  3. Open Bondage Club, log in, then click the bookmark. Open SlimeBeep and tap the slime-hacker tab (or type !cheats in a SlimeBeep chat).

Click it each time you open the game. It always loads the newest SlimeCheat, so there's never anything to update. Clicking it twice does nothing extra.

On a phone, or can't drag?
  1. Bookmark this page (or any page), then edit that bookmark.
  2. Name it slimecheat and paste one of these as its address (URL):

With Violentmonkey or Tampermonkey: install SlimeCheat. It starts with the game every time, and updates itself.
