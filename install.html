SlimeCheat

A hack panel inside SlimeBeep for Bondage Club. Made by SlimeQueenSamantha.

⚠ First: SlimeBeep

SlimeCheat opens inside SlimeBeep's window, so you need SlimeBeep (or turn it on in FUSAM). No SlimeBeep yet? The SlimeBeep + SlimeCheat bookmark below loads both.

🔖 Bookmark (no extension needed, phones too)

Pick one: SlimeCheat if SlimeBeep already loads by itself (FUSAM or its userscript), or SlimeBeep + SlimeCheat if not.

💻 On a computer: drag it

Show your bookmarks bar (Ctrl + Shift + B) and drag this button onto it:

💻 SlimeCheat

📱 On a phone (or if dragging doesn't work)

  2. Make a new bookmark: on a computer press Ctrl + D on this page; on a phone tap ☆ (or ⋮ › ☆).
  3. Edit it (on a phone: ⋮ › Bookmarks, then the bookmark's ⋮ › Edit): name it slimecheat, and replace its address (URL) with what you copied. Save.
    ⚠ The address must start with javascript:. Some browsers (Chrome) drop that word when you paste; if it's missing, type javascript: back at the very start. Without it the browser just searches for the code.
  4. Open Bondage Club and log in, then open the bookmark:
    • Computer: click it in your bookmarks.
    • Phone: type slimecheat in the address bar and tap the bookmark in the suggestions, not a search (phones only run bookmarks this way).
  5. Open SlimeBeep and tap the slime-hacker tab (or type !cheats in a SlimeBeep chat).

Open it each time you open the game. It always loads the newest SlimeCheat, so there's never anything to update. Opening it twice does nothing extra.
